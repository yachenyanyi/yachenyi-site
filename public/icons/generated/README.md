# Generated icon concepts

These icons belong to the Yachenyi visual system and stay neutral until assigned to a concrete UI role.

When adopted by a component, rename or copy the chosen asset to a semantic filename such as:

- `service-ai-agents.webp`
- `service-automation.webp`
- `project-runtime.webp`
- `lab-research.webp`

Do not use icons only as decoration; prefer them where they improve navigation or comprehension.
