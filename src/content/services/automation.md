## What I build

Small pieces of software often create more leverage than large platforms when they remove a repeated manual process.

Typical work includes:

- browser and API automation
- data collection and transformation
- internal dashboards
- scheduled workflows
- integration between existing systems
- reusable developer utilities

## Approach

Automate the repeated decision path, preserve an audit trail and keep the escape hatch for manual intervention.
