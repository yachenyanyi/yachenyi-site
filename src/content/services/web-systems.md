## What I build

Web projects range from content-heavy public sites to focused internal applications. The implementation should match the actual product rather than defaulting to a large framework.

Typical work includes:

- static-first public websites
- product and project sites
- content systems
- internal web tools
- API-backed applications
- deployment and release automation

## Approach

Prefer simple architecture, meaningful HTML and stable URLs. Add runtime complexity only when the product genuinely needs it.
